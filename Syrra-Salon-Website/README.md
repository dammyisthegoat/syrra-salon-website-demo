# Syrra Salon Website

A complete static website concept for Syrra Salon, Charleston, West Virginia.

## Files
- `index.html` — page structure
- `styles.css` — responsive styling and animation
- `script.js` — navigation, reveal effects, tilt, magnetic buttons, lightbox and scroll behavior
- `assets/gallery/` — gallery images prepared from the Instagram screenshots supplied for this concept
- `assets/brand/` — profile logo crop supplied for this concept

## Run locally
Open `index.html` directly in a browser.

## GitHub Pages
Upload the contents of this folder to a repository and enable GitHub Pages from the repository settings.

## Important
The gallery imagery was prepared from screenshots supplied during the build. Before presenting a final production site to the salon, replace those crops with original/high-resolution images provided or approved by Syrra Salon.
